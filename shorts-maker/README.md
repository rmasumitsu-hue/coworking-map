# shorts-maker

`script.txt` から縦型ショート動画（1080x1920、60秒以内）を自動で作るツールです。
音声は VOICEVOX Engine で作り、動画は MoviePy で書き出します。

## 準備

```bash
pip install -r requirements.txt   # ffmpeg も必要（MoviePy が使います）
```

VOICEVOX Engine を `http://localhost:50021` で起動しておきます（VOICEVOX アプリを起動するだけでもOK）。

## 素材の置き場所

| ファイル | 内容 |
|---|---|
| `images/background.png` | 背景（画面いっぱいに拡大して切り抜きます） |
| `images/報告者.png` `images/義母.png` `images/アシスタント.png` | キャラ画像（背景が透明なPNGがおすすめ） |
| `images/報告者_口半.png` `_口開` `_目閉` `_目閉_口半` `_目閉_口開` | 表情の差分（任意）。あると口パク・まばたきします |
| `sounds/<名前>.mp3` | `［SE:ドン］` なら `sounds/ドン.mp3`（.wav でも可） |
| `sounds/bgm.mp3` | BGM（音量15%で動画の長さに合わせてループします） |
| `fonts/*.ttf` / `*.otf` | 好きな日本語フォントを置くと優先して使います（任意） |

ファイルがない素材は警告を出してスキップします（背景はグラデーション、キャラは非表示）。
とりあえず試すなら、仮素材を作れます: `python make_placeholders.py`
（オリジナルのアニメ風キャラ3人を、表情差分つきで描きます。`--force` で作り直し）

## キャラの動き

| 動き | 内容 |
|---|---|
| 口パク | 声の大きさに合わせて「閉じ・半開き・開き」を切り替え（`_口半` `_口開` の画像を使用） |
| まばたき | 3〜5秒ごと。たまに2回続けて（`_目閉` の画像を使用） |
| 呼吸・弾み | 待機中はゆっくり上下し、話すときは声に合わせて弾む |
| 登場 | 話すキャラが替わると、下から少し飛び出す |
| 画面揺れ | `［SE:ドン］` `［SE:ガシャーン］` で画面が揺れる（`animation.shake_se` で変更） |
| テロップ | 大きく出てから元の大きさに戻る |

差分画像がなければ、1枚の画像のまま呼吸・弾み・登場の動きだけをつけます。
画像のないナレーターが話している間は、直前のキャラが待機姿勢で残ります。
動きの大きさや速さは `config.json` の `animation` で調整できます。

## 使い方

```bash
python make_short.py                    # script.txt → output/short.mp4
```

次の動画を作るときは、`script.txt` を差し替えて同じコマンドを実行するだけです。
台本を何本かまとめて作ることもできます。

```bash
python make_short.py scripts/ep02.txt scripts/ep03.txt   # → output/ep02.mp4, output/ep03.mp4
python make_short.py --mock-tts          # VOICEVOXなしで動作確認（音声は無音）
python make_short.py --no-render         # JSONと音声だけ作る（長さの確認用）
```

## 台本の書き方

```
［SE:ドン］
義母：こんな犬の餌、誰が食べるのよ。
［テロップ:嫁の料理をゴミ箱へ直行させる義母］
報告者：結婚して2年。義実家と同居中。
```

- `キャラ名：セリフ` を1行に1つ書きます（全角・半角のコロンどちらでも可）。
- `［SE:〇〇］` は `sounds/〇〇.mp3` を、次のセリフの頭で鳴らします。
- `［テロップ:〇〇］` は、次のセリフの頭から1.5秒、画面中央に赤い大文字で出します。
- 台本の最後に置いた SE やテロップの分は、字幕なしの画面を延長します。
- 空行と ``` ・ `#` で始まる行は無視します。
- `悪役` → 義母、`逆転役` → アシスタント として読みます（`config.json` の `aliases`）。

## 処理の流れ

1. 台本を「セリフ・SE・テロップ」に分けて `output/short.json` に保存します。
2. VOICEVOX の `/speakers` から話者IDを調べ、各セリフの音声を作ります（話速1.2）。
   作った音声は `output/cache/` に保存し、同じセリフと話速なら作り直しません。
3. セリフの音声の長さに合わせて画面を切り替え、キャラを動かします（背景＋話しているキャラ＋下に字幕。字幕は1行15字で改行し、句読点が行頭に来ないようにします）。
4. 声・SE・BGM（15%）を重ねて、`output/short.mp4` に書き出します。
5. 長さを表示します。60秒を超えたら必要な話速を計算して上げ、作り直します（上限2.0）。

## キャラ・声の割り当て（config.json）

| キャラ | VOICEVOX 話者 | 画像 |
|---|---|---|
| 報告者 | 春日部つむぎ（ノーマル） | images/報告者.png |
| 義母 | 四国めたん（ノーマル） | images/義母.png |
| アシスタント | 冥鳴ひまり（ノーマル） | images/アシスタント.png |
| ナレーター | 青山龍星（ノーマル） | なし（背景と字幕だけ） |

新しいキャラを出すときは、`characters` に1行足します。スタイル名（例: `"あまあま"`、`"ツンツン"`）も変えられます。
字幕やテロップの大きさ・色・位置、話速の上限、セリフの間（`pause_after_line`）も `config.json` で調整できます。

## 目安

話速1.2のとき、60秒に収まるのは本文がおよそ450〜500字（30行前後）までです。
話速が1.6を超えると聞き取りにくくなるので警告を出します。そのときは台本を削ってください。
